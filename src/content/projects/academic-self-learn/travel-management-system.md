## ⚡ Overview & Scope

Developed a travel agency exploration platform built to study full-stack web architecture using the **MEAN stack (MongoDB, Express.js, Angular, Node.js)**. The project established the complete visual interface and foundational backend authentication/document layer:

1. **Travel-V1**: An interactive frontend prototype (HTML5, CSS3, JavaScript) validating travel package layouts, itinerary showcases, and mobile-friendly booking forms.
2. **Travel-V2**: A **MEAN stack** implementation establishing **Angular** components, **Node.js / Express** RESTful service scaffolding, **MongoDB** document schemas, and user authentication flows.

> *Note: This project serves as an architectural prototype focusing on frontend component design, auth integration, and NoSQL data structures.*

## 🧠 Why I Used This Tech Stack

- **Why Angular?** Modular TypeScript architecture and reactive components allowed clean organization of travel package cards and forms.
- **Why MongoDB & Express?** Flexible JSON-like document storage naturally models travel packages with varying sub-itineraries without strict tabular schemas.

## 🚀 Impact & What I Learned

- **Full-Stack Synergy**: Gained early hands-on understanding of how modern JavaScript/TypeScript SPAs communicate with REST backends and NoSQL databases.
